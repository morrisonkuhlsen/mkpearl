# Roadmap

Pearl's plan and progress log. Each section says what is done and its **Next:** items, the work list.

## The editor
- *Done:* Typst compiled in-process and incrementally; live pages, clicking a page to reach its
  source and back; ribbon, File view, rail, strip and status bar after MK Matrix and MK Perth; themes;
  splash; autocompletion, closing brackets, hover help, search and replace; rulers; spell checking in pt-BR;
  images by pasting and dragging; a References pane, with DOIs and a check of the citations;
  typing on the pages, dragging the margins on the rulers, and selecting, resizing, moving and
  removing figures on the pages.
- *Done:* ready-made formulas, with previews and a search.
- *Done:* letterhead and watermark, with a live preview and the opacity of a picture.
- *Done:* the typography watch (#27); layout variants (#25); fitting in a number of pages (#26); the accessibility check and PDF/UA-1 export (#30).
- *Done:* the Documentation pane: lessons in both languages with live examples, a search, and a
  reference of every function from Typst itself.
- Known: #4, #5, #15.
