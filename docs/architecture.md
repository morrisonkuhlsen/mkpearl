# Architecture

One crate for now (#1).

| Module | What it holds |
| --- | --- |
| `app`, `app/backstage` | the window and the File view |
| `compiler` | a worker thread: compiling, rendering pages, PDF, completions, hover; `world` is what Typst sees |
| `collab` | sessions: `doc` (the yrs document), `net` and `wire` (Noise over TCP) |
| `assistant` | Claude, joining as a peer through the same session link, by the raw Messages API |
| `history` | versions, whole copies under the user's data folder |
| `recovery` | copies of unsaved text beside a lock the system releases when a run ends |
| `ruler` | drawing the rulers; `compiler` measures the margins |
| `edit`, `typing`, `highlight` | editing commands, typing help and colours from Typst's parser |
| `theme`, `icons`, `widgets`, `splash` | the look, adapted from MK Matrix and MK Perth |
| `recent`, `templates`, `sample` | settings, the starting documents |
| `licenses` | `THIRD-PARTY-LICENSES.txt`, generated by `examples/licenses.rs` |

## Threads

The window never waits. The compiler and each session have threads of their own, and talk to the
window through channels, waking it when there's something to show.

## Margins

Typst keeps no margins on the pages it returns, and what's on a page says nothing reliable about
them: its body is usually dissolved into the page. A second compile, in a world of its own, adds a
last page that reports its writing area.
