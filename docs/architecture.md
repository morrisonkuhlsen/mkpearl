# Architecture

One crate, by the owner's decision: nothing needs the split yet, and it would touch all the code (#1).

| Module | What it holds |
| --- | --- |
| `app`, `app/backstage` | the window and the File view |
| `compiler` | a worker thread: compiling, rendering pages, PDF, completions, hover; `world` is what Typst sees |
| `collab` | sessions: `doc` (the yrs document), `net` and `wire` (Noise over TCP) |
| `assistant` | Claude, joining as a peer through the same session link, by the raw Messages API |
| `images` | pictures brought in by paste, drag or dialog: copied beside the document, never over a file |
| `bib` | the references in the document's `.bib` files, read by the library Typst uses, on a thread of their own |
| `doi` | what goes out, only when asked: a DOI's entry from doi.org, and each reference's lookup there or at Crossref |
| `guide`, `app/docs` | the documentation: lessons from `locales/guide/`, the reference from Typst's own text, examples compiled in a world of their own |
| `app/figures`, `ruler` | editing on the pages: what the pointer does becomes one edit of the source |
| `formulas`, `app/formulas` | the ready-made formulas, from `locales/formulas.txt`, previewed by the compiler's examples |
| `letterhead`, `app/letterhead` | the settings, the rule they become and the block that holds them in the source |
| `compare`, `app/comparing` | what changed between two versions, word by word, and where it falls on their pages |
| `typography`, `app/typography` | what reads badly on the finished pages, from the layout and the source's structure, after each compile; `accessibility` adds what keeps a document from reaching everyone |
| `app/accessibility` | the warning before exporting, and why an accessible PDF was refused |
| `variants`, `app/variants` | other ways to set a document, as the edit each would make; compiled on a thread of their own, so typing doesn't wait |
| `fit`, `app/fit` | the smallest layout changes that reach a number of pages: the ladder and the search, compiled on a thread of their own |
| `timeline`, `app/timeline` | a slider over the versions and their pages, and what each says that the document no longer does, read in blocks by Typst's parser |
| `comments`, `app/comments` | threads tied to a passage, as flat entries a session shares in its document, in a file beside the document |
| `history` | versions, whole copies under the user's data folder |
| `recovery` | copies of unsaved text beside a lock the system releases when a run ends |
| `spell` | words from Typst's parser, checked by `spellbook` on a thread of its own |
| `ruler` | drawing the rulers; `compiler` measures the margins |
| `edit`, `typing`, `highlight` | editing commands, typing help and colours from Typst's parser |
| `theme`, `icons`, `widgets`, `splash` | the look, adapted from MK Matrix and MK Perth |
| `recent`, `templates`, `sample` | settings, the starting documents |
| `i18n` | the message catalogs (`locales/*.ftl`), `tx` and `tr!`, adapted from MK Perth |
| `licenses` | `THIRD-PARTY-LICENSES.txt`, generated by `examples/licenses.rs` |

## Threads

The window never waits. The compiler and each session have threads of their own, and talk to the
window through channels, waking it when there's something to show.

## Margins

Typst keeps no margins on the pages it returns, and what's on a page says nothing reliable about
them: its body is usually dissolved into the page. A second compile, in a world of its own, adds a
last page that reports its writing area.
